# Note a pay — PWA Android v1.4

แอปบันทึกรายรับรายจ่ายสำหรับ Android ผ่านเบราว์เซอร์/PWA ข้อมูลจัดเก็บใน LocalStorage ของอุปกรณ์

## ฟีเจอร์
- ภาพรวมรายรับ รายจ่าย และยอดคงเหลือรายเดือน
- เพิ่ม/แก้ไข/ลบรายการ พร้อมแนบรูป
- ค้นหารายการและกรองตามเดือน
- เป้าหมายออมเงินหลายรายการ พร้อมรูปและประวัติการออม
- บันทึกหนี้สินและการชำระคืน
- งบประมาณรายเดือนและงบประมาณแยกหมวดหมู่
- กระเป๋าเงินหลายใบและสรุปยอดแยกกระเป๋า
- แม่แบบรายการประจำ กดเพิ่มเข้ารายการในเดือนนั้นได้
- ปฏิทินการเงินและหน้าวิเคราะห์
- ธีม 6 แบบ ปรับสี ลวดลาย และภาพพื้นหลัง
- ส่งออก/นำเข้าข้อมูล JSON และ CSV (JSON รวมรูปภาพ)
- ใช้งานออฟไลน์หลังเปิดครั้งแรกผ่าน Service Worker

## ติดตั้ง/อัปเดต
1. อัปโหลดไฟล์ทั้งหมดใน ZIP ไปยัง root ของ branch `main` โดยแทนที่ไฟล์เดิม
2. Commit changes โดยตรงเข้า `main`
3. รอ GitHub Pages deploy แล้วเปิด URL ของ Pages ใหม่
4. หากแอปยังใช้ไฟล์เก่า ให้ปิดแท็บ/แอปแล้วเปิดใหม่อีกครั้ง

## ข้อควรทราบ
- ข้อมูลเก็บในเบราว์เซอร์/อุปกรณ์นี้ ไม่ได้ซิงก์ข้ามเครื่อง
- ก่อนอัปเดตหรือเปลี่ยนมือถือ ให้ส่งออก JSON สำรองไว้ก่อน
- LocalStorage มีข้อจำกัดพื้นที่ รูปภาพจะถูกบีบอัดก่อนบันทึก
- PIN/สแกนนิ้วมือและ Cloud Sync ยังไม่รวมในรุ่นนี้

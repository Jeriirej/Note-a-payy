# Note a pay — PWA สำหรับ Android

แอปเว็บแบบติดตั้งบนหน้าจอมือถือ (PWA) มี:
- บันทึกรายรับ/รายจ่าย หมวดหมู่ วันที่ และรายละเอียด
- ยอดรวมรายเดือนและเงินคงเหลือ
- วิเคราะห์รายจ่ายตามหมวดหมู่
- ตั้งงบประมาณรายเดือน
- Light/Dark mode
- เก็บข้อมูลในเครื่องด้วย localStorage
- ส่งออก/นำเข้า JSON และส่งออกรายงาน CSV
- Service worker สำหรับ cache เพื่อใช้งานออฟไลน์หลังเปิดครั้งแรก

## ติดตั้งบน Android
PWA ต้องเผยแพร่ผ่าน HTTPS ก่อน จึงจะแสดงคำสั่งติดตั้งได้อย่างถูกต้อง:
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไปยัง static hosting ที่รองรับ HTTPS (เช่น GitHub Pages).
2. เปิด URL ของเว็บไซต์ใน Chrome บน Android.
3. แตะเมนู ⋮ > Add to Home screen / Install app.

ไฟล์นี้เป็นเว็บแอป ไม่ใช่ APK และไม่ได้ซิงก์ข้ามอุปกรณ์หรือขึ้นคลาวด์ ข้อมูลจะอยู่ในเบราว์เซอร์/อุปกรณ์เครื่องนั้น ควรส่งออก JSON สำรองเป็นระยะ.

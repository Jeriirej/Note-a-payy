# Note a pay — PWA Android v1.3

อัปเดตจาก v1.1 โดยคงคีย์ข้อมูลเดิม `nap_entries`, `nap_theme`, `nap_budget` ไว้เพื่อให้รายการเดิมยังอยู่หลังอัปเดตบน origin เดิม

## ฟีเจอร์ใหม่
- หน้า **ออมเงิน** แยกต่างหาก สร้างเป้าหมายได้หลายรายการ
- ตั้งชื่อ ยอดเป้าหมาย วันครบกำหนด และแนบรูปภาพเป้าหมาย
- เพิ่มเงินออมแต่ละเป้าหมาย พร้อมแถบความคืบหน้าและประวัติ
- แนบรูปใบเสร็จ/รูปประกอบให้รายการรายรับรายจ่าย
- หน้า **หนี้สิน** แยก: คนอื่นยืมเรา / เรายืมคนอื่น พร้อมบันทึกการชำระคืน
- แจ้งเตือนเมื่อรายจ่ายเดือนนั้นเกินงบ
- กราฟรายรับ/รายจ่ายรายวัน และหมวดหมู่
- สำรอง/กู้คืน JSON รวมรูปภาพ เป้าหมาย และหนี้สิน

## อัปเดต GitHub Pages
อัปโหลดและแทนที่ไฟล์ `index.html`, `sw.js`, `manifest.webmanifest` ใน repository เดิม (โฟลเดอร์ root) แล้วรอ Pages deploy เสร็จ จากนั้นเปิดเว็บเดิมใน Chrome แล้วรีเฟรช หากยังเห็นเวอร์ชันเก่า ให้ปิดแอปจาก recent apps แล้วเปิดใหม่ หรือเปิด URL เดิมใน Chrome แล้ว refresh

**สำคัญ:** อย่าลบ repository และอย่าเปลี่ยน URL เพราะจะช่วยให้ข้อมูลเดิมที่บันทึกในเบราว์เซอร์ยังอยู่ ข้อมูลในเครื่องไม่ซิงก์ข้ามอุปกรณ์ ควรส่งออกไฟล์สำรองก่อนอัปเดตเพื่อความปลอดภัย

รูปภาพจะถูกย่อและบีบอัดก่อนเก็บใน localStorage ของเบราว์เซอร์ ข้อมูลทั้งหมดอยู่ในอุปกรณ์นี้ ไม่ได้ส่งขึ้นคลาวด์ การแนบรูปจำนวนมากอาจใช้พื้นที่จัดเก็บได้


## ปรับแต่งธีม (v1.3)
- ธีมสำเร็จรูป 6 แบบ: มิ้นต์, ซากุระ, ลาเวนเดอร์, ท้องฟ้า, พีช และมินิมอล
- เลือกสีหลักเองจากตัวเลือกสี
- เลือกลวดลายพื้นหลัง: เรียบง่าย, จุด, ตาราง, หัวใจ, ดาว และดอกไม้
- เลือกรูปจากมือถือเป็นภาพพื้นหลังได้ โดยระบบย่อรูปก่อนจัดเก็บ
- การตั้งค่าธีมเก็บไว้ใน LocalStorage บนอุปกรณ์นี้
